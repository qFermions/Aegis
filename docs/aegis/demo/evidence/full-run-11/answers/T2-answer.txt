**Why this order**
- Okta goes first because it creates the Google accounts.
- With Okta's default settings, deactivating the user also suspends their Google account. If the integration is set to "Do not suspend user", Google stays active.
- There's no lighter option for a leaver. Suspending in Okta keeps every app assignment, so it doesn't remove anything.
- Turning off Okta sign-in doesn't remove someone from the GitHub organization, and it doesn't suspend their Linear seat unless Linear is set to follow Okta automatically (SCIM). So steps 3 and 4 are separate changes.

**Each change and its check**
- Step 2 (deactivate in Okta): R3. Double-check: Aegis reads Okta as Deactivated, then Google as Suspended.
- Step 3 (remove from the GitHub organization): R3. Double-check: Aegis reads that they are not a member, not invited and not an outside collaborator.
- Step 4 (suspend in Linear): R3. Double-check: Aegis reads the Linear member as inactive.
- Step 4, if Linear follows Okta automatically (SCIM is on): don't suspend by hand. Wait for Okta's change to reach Linear, then run the same check.
- Only if Google still shows Active after step 2: gate `gws-offboard-suspend-portal`.

**Stop conditions in GitHub**
- They are an owner and there are 2 owners or fewer. Add another owner first.
- They are the only admin of a repository. Give someone else admin first.
- A fork holds work nobody else has, and the repository owner hasn't decided what to keep.

**Mail, cost and the restore window**
- **Mail:** a suspended Google account gets no new mail. If the manager wants it forwarded, that is a separate change, and it must be in place before Friday 18:00. Name who receives the mail and the end date.
- **Cost:**
  - Google: a suspended account is billed at the full rate. The Archived User licence is the cheaper way to keep the data.
  - GitHub: the paid seat count doesn't drop on its own. Lowering it is a separate billing step.
  - Linear: a suspended member drops off the next bill.
  - Okta: whether a deactivated user counts toward the licence isn't confirmed. Check the contract.
- **Restore window:**
  - Okta: a deactivated account can be turned back on.
  - GitHub: a removed member can be reinstated with their settings for 3 months.
  - Linear: unsuspending reverses it.
  - Google: suspension deletes nothing. A later deletion leaves 20 days to restore.
