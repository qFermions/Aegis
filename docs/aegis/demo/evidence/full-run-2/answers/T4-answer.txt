## Details
**Gate status:** the shared-mailbox runbook has no reviewed safety gate for these two grants yet. It only has preview markers. A human admin makes the change in the portal after the callback and approval. Aegis doesn't make it.

**Risk:** two single reversible writes on one mailbox for one user (R1). Not destructive.
- **Undo:** remove [UPN] from Full Access and from Send As in the same Delegation pane.

**Notes**
- Send As and Send on Behalf are different. The ticket asks for Send As, so mail will look like it came from the mailbox itself. Don't add Send on Behalf.
- Accounts here are cloud-only, so nothing needs to sync.
- Outlook can take up to 60 minutes to show the mailbox automatically. If it still doesn't appear, restart Outlook or add the mailbox by hand under Account settings.
