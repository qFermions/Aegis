## Fix
**What's wrong:** The requester wants access to the shared billing mailbox and doesn't have it yet.
**Do this:**
1. Call the requester back on the number in the firm's staff list to confirm the request is really from them.
2. Get the managing partner's written approval for this person to open the billing mailbox.
3. Open Exchange admin center → Recipients → Mailboxes → billing mailbox → Mailbox Delegation. Copy the Full Access and Send As lists into the ticket, and note what [FIRST_NAME] holds.
4. After approval, give Full Access only: Read and manage → Edit → Add members → [UPN] → Save → Confirm.
**Done when:** [UPN] appears under Read and manage. Aegis then checks the grant is in place.
**Stop if:** the callback fails, approval is refused, or "billing" turns out to be a group rather than a shared mailbox.
**Tell the user now:** IT got your request. We'll call you to confirm it, and the managing partner needs to approve it.
**Tell the user when done:** The billing mailbox is set up for you. It will show up in Outlook by itself. Restart Outlook if you don't see it.
