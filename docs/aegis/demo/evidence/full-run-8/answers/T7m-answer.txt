## Fix
Assumed setup: Jamf Pro and the office internet line (the setup given does not list the office network equipment or internet provider).

**What's wrong:** Video calls freeze for the whole office. Nobody knows yet whether the cause is the Wi-Fi, the internet line, or something using up the bandwidth.

**Do this:**
1. Work out how wide it is. Is it everyone in the office, or remote staff too? Is it only Zoom, or are other sites slow as well? Check Zoom's status page and the internet provider's status page.
2. On one office Mac next to the Wi-Fi point, run a speed test over Wi-Fi, then again over a cable. If the cable is fast and Wi-Fi is slow, it's the Wi-Fi. If both are slow, it's the line.
3. Compare the result to the speed the studio pays for.
4. In Jamf Pro → Computers → [DEVICE_NAME] → History → Policy Logs, look for large updates or installs that ran while it was slow. Also ask whether big Drive syncs were running.
5. On the office router's admin page, see which device is using the most traffic.

**Done when:** a Zoom test call on office Wi-Fi runs without freezing.
**Stop if:** remote staff are slow too, or a status page lists an outage.

**Tell the user now:** IT is checking whether this is the Wi-Fi or the internet line. When a call freezes, please note the time and where you were sitting.
**Tell the user when done:** We found what was slowing calls and dealt with it. Please tell us if a call freezes again.

Full notes: see Details.

**Why these steps:**
