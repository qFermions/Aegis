## Details
- **Runbook:** `/shared-mailbox`, which has one gate for each grant. The replay lookup was a MISS. In the runbook, `[MAILBOX]` means this ticket's `[SHARED_MAILBOX]`.
- **Class:** each grant is R2. Once someone has Full Access, what they read can't be unread. Mail sent as the mailbox can't be recalled.
- **How to undo:** `/mailbox-permissions` removes each grant separately, with gates [mailbox-permission-remove-portal] and [mailbox-send-as-remove-portal].
- **Double-check for each grant:** Aegis runs a read-only check after each change (the commands are in the block below).
- **Licence:** a shared mailbox needs no licence while it's under 50 GB.
- **Send As vs. Send on Behalf:** Send As shows only the mailbox as the sender. If the firm wants recipients to see "[UPN] on behalf of [SHARED_MAILBOX]", that's Send on Behalf. The admin center can't set it for a shared mailbox, and the runbook only has it as a preview, not a gated change.
- **Outlook:** the mailbox appears in Outlook automatically, but it can take a while. If it still hasn't appeared after that, remove and re-add the account's Outlook profile.
- **Customer profile:** cloud-only accounts, so there's no on-prem sync to wait for. Do the change during business hours (Mon–Fri, 08:30–17:30).
