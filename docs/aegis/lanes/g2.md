# Lane G2: Google Workspace, Fleet, Jamf Pro, Slack and Linear

Lane G2 makes Aegis an IT department for a company that runs Google Workspace for identity and mail, Jamf Pro and Fleet for Apple and fleet device management, Slack for communication and Linear for IT tickets. Written 2026-10-27 on branch `feat/g2-gws-fleet-jamf-slack-linear` (base `3592bd1`, stacked on draft PR #4).

The product boundary holds for every line below: AEGIS ADVISES; HUMANS EXECUTE PRODUCTION CHANGES. In this lane that means: Aegis never sends a Slack message, reaction, invite or channel change; never writes a Linear issue, comment, state or label; never starts a Fleet or Jamf lock, wipe, script, policy or live query; never makes a Google Workspace user, group, 2-Step Verification, device or Drive change. Aegis reads through the read-only adapters (`scripts/adapters/`), writes procedures, drafts and ticket notes, and proves a human's write with a `verify-*` read.

Each platform is proven separately: its own jobs, its own commands, its own corpus tickets (`scripts/eval/g2-tickets.json`, `platform` field), its own adapter and tests, its own capability-map rows. No row below names two platforms.

### Read-only API surface (`scripts/adapters/gws-client.js`)

Hosts: `admin.googleapis.com` (fixed); token exchange at `oauth2.googleapis.com` path `/token` (fixed). Credentials: `GWS_SA_CLIENT_EMAIL`, `GWS_SA_PRIVATE_KEY` (the service account's PEM key, from the environment only), `GWS_ADMIN_SUBJECT` (the admin the service account impersonates). Token exchange: `POST /token` with exactly `grant_type` and `assertion` (an RS256 JWT signed in the adapter with the read-only scopes below), never retried. Tenant: `GWS_CUSTOMER_ID`; a record whose `customerId` is another customer's is refused.

Scopes requested (read only): `admin.directory.user.readonly`, `admin.directory.group.readonly`, `admin.directory.rolemanagement.readonly`, `admin.directory.device.mobile.readonly`, `admin.directory.device.chromeos.readonly`, `admin.reports.audit.readonly`, `admin.reports.usage.readonly`.

| Read | Method and path | Used for |
|---|---|---|
| user | GET `/admin/directory/v1/users/:userKey` | `suspended`, `isEnrolledIn2Sv`, `isEnforcedIn2Sv`, `isAdmin`, `orgUnitPath`, `customerId`; `verify-suspended`, `verify-2sv-enforced`, `verify-ou` |
| users | GET `/admin/directory/v1/users?customer=my_customer` (query, maxResults, pageToken) | users not enrolled in 2-Step Verification; super admins |
| roles | GET `/admin/directory/v1/customer/my_customer/roles` | role ids and names |
| role assignments | GET `/admin/directory/v1/customer/my_customer/roleassignments` (userKey, roleId) | `verify-admin-role-removed` |
| group members | GET `/admin/directory/v1/groups/:groupKey/members` | exception groups |
| mobile devices, ChromeOS devices | GET `/admin/directory/v1/customer/my_customer/devices/mobile`, `/devices/chromeos` | endpoint posture |
| activities | GET `/admin/reports/v1/activity/users/:userKey/applications/:applicationName` (admin, login, drive, token, saml, user_accounts; startTime, endTime, eventName, maxResults) | who shared externally, admin setting changes, OAuth grants; `verify-event` |

Refused before credentials or network: every POST, PUT, PATCH and DELETE on `admin.googleapis.com` (user insert, update, delete, makeAdmin, signOut, role assignment insert and delete, group and member changes, device actions, token and ASP deletes), any scope that is not on the read-only list, and a token exchange that carries any field besides `grant_type` and `assertion`.
