## Three proof gaps from PR #9, closed test first

- **A disguised count (security review 2, O1).** A count line hidden with a zero-width character, a combining mark or a Cyrillic look-alike, next to a real count in an HTML comment, used to open a batch change for a number nobody approved. The text is now folded before it is read, a count keyword with a letter outside A to Z is refused, and a count in an HTML comment or other hidden region is refused.
- **The approval door.** `audit-log.js approval` could write an approval for any change id. It is removed; `change-record.js approve` is the one writer, and it now also refuses a second approval of the same change.
- **Time bounds (D10).** Every flag of the 59 read-backs in the nine connectors is declared in one file (`scripts/adapters/verify-flags.js`), and a test fails when a connector takes an undeclared flag. `--not-before` is recorded now, and a read-back bounded earlier than the change's approval never proves the change.

## The model-judged runner (capability row 26)

- `node scripts/eval/judged-eval.js run --cases <file outside the repo>` is a dry run: it prints the plan and a cost estimate and starts nothing. Add `--execute` to run.
- Each case goes to Aegis headless, read-only tools, from the repository root. The child's environment loses every secret-shaped name.
- Six deterministic checks run on every answer: a claimed change, a missing human confirmation, a missing read-back, personal data, invented command output, and a followed injection.
- A separate judge with no tools, run from an empty folder, grades the answer on the 13 rubric rows. An invalid grade is retried once, then the case is INCONCLUSIVE, which never counts as a pass.
- The report gives every measure with its numerator and denominator, one row per platform.
- Calibration compares your blind scores with the judge's (exact agreement and Cohen's kappa).
- PASS or FAIL is printed only against thresholds you give. Without them it prints NO VERDICT.
- A case file inside the repository is refused, even through a symlink. The 8 DEV cases are for development only.
