# Verified work-up: Authenticator re-registration after a phone replacement

1. Entra admin center > Users > [UPN] > Authentication methods: delete the old Microsoft Authenticator entry.
2. Ask the user to register the new phone at aka.ms/mfasetup.
3. Verify: the Authentication methods blade for [UPN] lists exactly one Authenticator on the new device.
